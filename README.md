# Make Knowledge Cards

一个用于把文章、Markdown 或纯文本整理成知识卡片的 Codex skill。

它会提取原文中真正重要的知识点，每张卡片只讲一个点，并合并重复内容。默认生成 5–8 张卡片；如果原文没有足够多彼此独立的重要知识点，会减少数量，而不是补写原文没有的信息。

## 使用方法

直接在 Codex 中调用：

```text
$make-knowledge-cards
```

然后粘贴文章，或者提供本地 `.md` / `.txt` 文件路径。例如：

```text
$make-knowledge-cards 请阅读 path/to/article.md，并整理成知识卡片。
```

该 skill 支持：

- 直接粘贴的文章或文本
- 本地 Markdown 文件
- 本地纯文本文件

暂不支持网页抓取、PDF、Anki 和图形界面。

## 输入输出示例

输入：

```text
$make-knowledge-cards

番茄在温度低于 10°C 时生长明显变慢。低温会降低根系吸收能力，
因此降温后应减少浇水，否则土壤长期过湿容易伤根。恢复适温后，
植株通常需要几天才能恢复生长速度。
```

输出：

```markdown
### 1. 低温会明显减慢番茄生长

- **核心知识：** 番茄在温度低于 10°C 时生长会显著变慢。
- **简明解释：** 低温是影响生长速度的环境条件，也是后续管理变化的依据。
- **例子或自测：** 为什么番茄在低于 10°C 时生长明显变慢？

### 2. 低温降低根系吸收能力，降温后应减少浇水

- **核心知识：** 低温会降低番茄根系的吸收能力，因此降温后应减少浇水。
- **简明解释：** 减少浇水不是独立偏好，而是为了适应根系吸收能力下降。
- **例子或自测：** 降温后如果不减少浇水，可能带来什么问题？

### 3. 土壤长期过湿会伤根

- **核心知识：** 番茄在降温后若土壤长期过湿，容易伤根。
- **简明解释：** 这是低温条件下仍需控制浇水的原因。
- **例子或自测：** 降温后土壤长期过湿会对番茄造成什么风险？

### 4. 恢复适温后生长不会立即恢复

- **核心知识：** 番茄恢复到适宜温度后，通常需要几天才能恢复生长速度。
- **简明解释：** 温度改善与生长速度恢复之间存在延迟。
- **例子或自测：** 番茄恢复适温后，生长速度会立刻恢复正常吗？

本次共生成 4 张；原文没有足够多彼此独立的重要知识点来达到 5 张。
```
